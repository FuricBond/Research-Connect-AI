# Phase 2.4K Architecture — Frontend Discovery Experience & Production Hardening

## 1. Executive Summary

Phase 2.4K addresses the two primary P0 architectural gaps identified in the Post-Phase 2.4J Discovery Audit:
1. **Frontend Discovery Integration Gap**: Replaces the legacy Phase 1 list-only interface with a full-featured, multi-view React discovery application that completely integrates the Phase 2.4 Discovery APIs (`/api/v1/discovery/*`).
2. **Production API Hardening Gap**: Implements configurable in-memory sliding-window rate limiting and deterministic response caching for public discovery search and matching routes.

### 2.2 Core Frontend Capabilities

#### A. Literature Search (`DiscoverySearch.tsx`)
- Multi-channel hybrid search combining dense semantic vectors and PostgreSQL Cover Density FTS.
- **Academic Query Intelligence Banner**: Displays detected acronyms (e.g. `GNN`, `LLM`, `RAG`) and their expanded canonical terms.
- Quick suggestion chips for common academic queries.
- Bounded limit and offset pagination.
- Filter controls for publication year, work type, open access, citations, and ranking mode (`GENERAL`, `RESEARCH_SIMILARITY`, `RESEARCH_OPPORTUNITY`).

#### B. Similar Research Explorer (`SimilarResearch.tsx`)
- Evaluates nearest semantic neighbors and canonical taxonomy DAG proximity relative to a selected source paper.
- Shows shared topic badges and publication recency indicators.
- One-click transition to opportunity matching for any similar paper.

#### C. Opportunity Matcher Dashboard (`OpportunityMatches.tsx`)
- Matches academic venues (conferences, journals, workshops, CFPs) to a manuscript.
- **Quality Indicators**: Visually distinct Tier 1 (Scopus, Web of Science, IEEE, ACM, PubMed) and Tier 2 (DOAJ, Springer, Elsevier) badges with composite quality scores.
- **Predatory Risk Alerts**: High-visibility warning banners when a venue is flagged or exhibits high risk scores ($\ge 0.70$), with listed risk reasons and rank penalty notice.
- **Deadline Urgency**: Interactive countdown chips (`X days remaining`, `Deadline passed`, `Due MM/DD/YYYY`).

#### D. Slide-Over Explainability Drawer (`ExplainabilityDrawer.tsx`)
- 100% deterministic, zero-LLM ranking rationale generated by `ResultExplainer`.
- Natural language summary card and primary ranking drivers.
- **Signal Contribution Visualization**: Percentage-based visual progress bars for each active ranking signal ($w_i \cdot s_i$) with qualitative tier assessments.
- **Topic & Provenance Evidence**: Lists shared canonical topics and retrieval channels (Semantic Dense, Lexical Cover Density, Hybrid Fusion).
- **Strengths & Limitations**: Color-coded checkmark strengths and warning limitations.

## 3. Backend Production Hardening Architecture

### 3.1 Sliding-Window Rate Limiter (`app.core.rate_limiter`)
- Thread-safe sliding-window rate limiter tracking client IP addresses.
- Configurable via `settings.discovery_rate_limit_per_minute` (default 60 req/min) and `settings.discovery_rate_limiting_enabled: bool`.
- Emits standard HTTP headers:
  - `Retry-After: <seconds>`
  - `X-RateLimit-Limit: <limit>`
  - `X-RateLimit-Remaining: <remaining>`
  - `X-RateLimit-Reset: <seconds>`
- Returns HTTP 429 Too Many Requests when limits are exceeded.
- Automatically purges stale IP windows periodically to prevent memory growth.

### 3.2 Deterministic Response Caching (`app.core.cache`)
- Thread-safe, memory-bounded LRU TTL response cache (`DiscoveryCache`).
- Generates deterministic SHA-256 cache keys based on endpoint path and sorted query parameters.
- Configurable via `settings.discovery_cache_ttl_seconds` (default 60s), `settings.discovery_cache_max_entries` (default 1000), and `settings.discovery_cache_enabled: bool`.
- Emits standard HTTP headers:
  - `X-Cache: HIT` (served from in-memory cache)
  - `X-Cache: MISS` (freshly evaluated and cached)
  - `Cache-Control: public, max-age=<remaining_ttl>`

### 3.3 Correlation ID Middleware (`app.main`)
- Propagates existing or generates new UUID `X-Request-ID` headers across all incoming requests and outgoing responses.
